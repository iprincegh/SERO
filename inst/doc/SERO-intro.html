Overview

SERO is an R package for fast, robust emergency service location optimization and mapping. This vignette demonstrates the main workflow and visualization features.

Quick Start

library(SERO)

# Load example data
example_data <- sero_load_data()

# Find optimal locations
optimal <- sero_find_optimal_locations(example_data)

# Plot results
sero_plot_optimal_locations(optimal)

Full Workflow Example

# Complete workflow with interactive mode
results <- sero_complete_workflow(launch_interactive = FALSE, quick = TRUE, num_locations = 5)
summary(results)

Visualizations

# Accident map
sero_plot_acc(example_data)

# Population map
sero_plot_pop(example_data)

Saving Results

sero_save_optimal_locations(optimal, db_path = "inst/gpkg/dataset.gpkg")
